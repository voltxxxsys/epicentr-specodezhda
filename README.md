# ЭПИЦЕНТР — премиальная демо-версия сайта (3D-концепция)

Демо-версия **многостраничного** сайта торгово-производственной компании «Эпицентр-Спецодежда»
(Пенза, [205200.ru](https://205200.ru/)): спецодежда, спецобувь и средства индивидуальной защиты.

Главная фишка — **3D-визуализация на первом экране**: хромированный манекен вращается при
скроллинге, и по мере прокрутки на него «надеваются» девять слоёв экипировки, а стоимость
комплекта собирается из реальных цен каталога. Фон — процедурный шейдер **жидкого металла**.

Это визуальная концепция: техническая часть (CMS, бэкенд, интеграция с 1С, оплата) — следующий этап.

---

## Быстрый старт

```powershell
cd S:\сайт
node _tools\serve.mjs        # http://127.0.0.1:4321
```

Открыть в браузере: <http://127.0.0.1:4321/index.html>

Сборка не требуется: чистые ES-модули, CSS и HTML. Всё работает и без интернета —
three.js и все изображения лежат локально.

### 3D-герой: как устроен

Два режима показа (переключатель внизу слева, выбор сохраняется в localStorage):

| Режим | Что происходит | Для чего |
|---|---|---|
| **Турн** | манекен вращается по скроллу, объёмная одежда садится слоями | широкие экраны |
| **Вертикаль** | фигура строго лицом к зрителю, фото-карточки товаров поднимаются снизу и складываются в комплект | телефоны (выбирается автоматически при узком экране) |

**Риг** (`js/three/rig.js`) — манекен на настоящем скелете:
* 21 кость (таз → 2 позвонка → шея/голова, плечо → локоть → кисть, бедро → колено → стопа → носок);
* тело — `SkinnedMesh`; **веса скина считаются автоматически** (`autoWeights`): для каждой вершины
  берётся расстояние до сегментов костей и распределяется по 3 ближайшим (степенная зависимость);
* «дыхание» — вращение костей (`spine`, `chest`, `neck`, `head`) поверх bind-позы, поэтому тело
  деформируется, а не просто покачивается целиком.

**Одежда** — 9 слоёв, каждый в двух видах:
* **оболочка** (`shell`) — процедурная 3D-одежда для режима «Турн»: куртка, брюки, ботинки, каска,
  жилет (спинка + полочки), полумаска, краги, привязь. Оболочки проявляются шейдерным
  растворением по 3D-шуму (`discard`, а не прозрачность — иначе ломается сортировка);
* **фото-карточка товара** (`assets/rig/*.png`) — реальное фото с карточки каталога, вырезанное
  по фону (48–64 % прозрачных пикселей), для режима «Вертикаль».

**Фон** — фрагментный шейдер жидкого металла: доменный варп FBM → нормали → отражение
панорамной «студии» + френель; «бурность» растёт к финалу прокрутки. В вертикальном режиме
включается **ортографическая камера** (кадр 2,05 м) — фигура и карточки без перспективных искажений.

**Производительность**: авто-снижение разрешения рендера при fps < 22, пауза цикла вне экрана,
тени — текстурой-декалью без shadow map.

### Пересборка спрайтов одежды

```powershell
node _tools\run_cutout.mjs        # вырезает фон у фото товаров → assets/rig/*.png + sprites.json
```

Алгоритм (`_tools/cutout.html`): фон определяется по углам карточки, тени по краям гасятся,
содержимое обрезается по границам, цветной ореол по кромке убирается, результат — PNG с альфой.
Важно: у куртки фон градиентный, поэтому у неё вырезка хуже остальных — её стоит пересобрать
с ручной маской.

### Дизайн-система

Тёмный премиум: графит `#08090b`/`#14171d`, зеркальный хром `#e9ecf0`, акцент — тёплый янтарь
`#ff6a1a` (перекликается с сигнальной спецодеждой). Шрифт Inter, крупная типографика,
стеклянные панели, зерно и виньетки. Всё — в `css/base.css` (общая система) и
`css/pages.css` (внутренние страницы).

Скрипты сбора (для повторного обновления):

```powershell
node _tools\scrape.mjs           # страницы сайта → _ref/*.html
node _tools\parse_products.mjs   # каталог с ценами и фото → _ref/products.json
node _tools\make_catalog.mjs     # витрина демо → data/catalog.json
node _tools\dl_products.mjs      # фото товаров → assets/products/
```

## Проверка в браузере

`_tools/cdp.mjs` — мини-драйвер Chrome DevTools Protocol (без зависимостей): собирает ошибки
консоли, делает скриншоты, выполняет отладочный JS.

```powershell
# скриншоты героя в трёх точках прокрутки
node _tools\cdp.mjs "http://127.0.0.1:4321/index.html" "top:0:1500" "mid:2600:1700" "dressed:3900:1700"

# мобильный вид (430×900)
node _tools\cdp.mjs "http://127.0.0.1:4321/index.html" --size=430x900 "mob:0:2000"

# рендер каждого слоя экипировки отдельно
node _tools\cdp.mjs "http://127.0.0.1:4321/index.html" x:0:800 --only
```

Особенность headless-режима: колесо мыши и `scroll`-события там не доставляются,
поэтому драйвер прокручивает страницу программно и синхронизирует 3D-сцену через
отладочный хук `window.__epHero.set(progress)` (в обычном браузере он не нужен —
сцена и интерфейс живут на настоящем событии `scroll`).

В консоли браузера доступны:
* `window.__hero` — сцена: `state`, `stages`, `snap(p)`, `showOnly(key)`, `setAngle(rad)`;
* `window.__epHero` — интерфейс героя: `set(p)`, `fires`, `progress`.

Скриншоты складываются в `_shots/`.
